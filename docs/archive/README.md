# Documentation archive

This is the single home for plans, feature drafts, target requirements, and
historical delivery records. These files are preserved for context, excluded
from GitHub Wiki, and do not establish current product support. Historical source
paths and measurements may describe code that has since moved.

Use the [current documentation](../README.md) when operating or changing Labello.

Put new non-current material here. Keep its meaning and evidence; remove document
metadata headers and use Git history for authorship and revisions. Promote an
implemented contract into a current guide instead of publishing its plan to the wiki.
